## What Financial Planner Does

Financial Planner brings several personal finance tasks into a single web application. Instead of separating budget reviews, ledger records, and investment projections across different tools, users can examine their current position and investigate potential long-term results in one place.

The application is suited to retirement planning as well as routine cash-flow review. Its Monte Carlo simulations produce a range of possible portfolio paths, helping users assess assumptions and make more informed financial choices.

## Using the Application

Enter the budget and ledger information for the period you want to analyze. Once the current data is available, run portfolio simulations to study how different assumptions may affect results over time.

A common sequence is:

1. Create or revise personal finance records.
2. Inspect the current ledger and budget position.
3. Execute a Monte Carlo portfolio simulation.
4. Compare the resulting retirement planning scenarios.
5. Change the inputs and run additional projections when needed.
